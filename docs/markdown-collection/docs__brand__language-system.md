# SCHLUESSELKINDER Language System

## 1. Core Principles

- German first. English appears as cold fragments, not translation filler.
- Use short lines, metadata, catalog language, and institutional restraint.
- Write like a label archive, not a marketing site.
- Let silence carry weight. Do not explain the atmosphere.
- Keep emotional temperature low: controlled, intimate, unsentimental.
- Treat music, garments, and objects as evidence.
- Protect the core system: chair as campaign environment, rune/key as institutional language.
- SHIBARI KAWAII uses Ropeface only as an artist-specific secondary mark.

## 2. Voice Rules

- Use nouns, fragments, timestamps, archive codes, and short imperatives.
- Prefer pressure over enthusiasm.
- Prefer location, condition, residue, and material over personality.
- Use bilingual fragments only when the second language sharpens the line.
- Keep lines publishable as captions, release notes, labels, or wall text.
- Avoid explaining what the brand is doing. State what remains.
- Use uppercase for artifacts, tracks, manifest lines, and system labels.
- Keep punctuation blunt: periods, slashes, colons. Rare commas.

Good pattern:

- "Nacht bleibt Material."
- "Afterhours is a method."
- "Archiv offen. Store geschlossen."
- "Kein heller Raum."

Bad pattern:

- "Join our community of underground creatives."
- "Discover exclusive drops."
- "A dark cyberpunk lifestyle brand."
- "Shop the vibe."

## 3. Forbidden Language

Never use:

- startup language: launch, ecosystem, platform, seamless, community, experience layer
- conversion language: shop now, buy now, discover, join us, sign up, limited hype
- lifestyle clichés: vibe, aesthetic, edgy, rebel, curated lifestyle, underground culture for everyone
- fake scarcity: only today, don't miss out, exclusive access, final chance
- horror language: cursed, haunted, nightmare, demon, blood ritual, evil, possessed
- cyberpunk overload: neon future, dystopian grid, chrome rebellion, digital underworld
- fetish decoration: bondage fantasy, kink-coded sales language, eroticized rope copy
- meme irony: chaotic, unhinged, lore, core, era, coded, slay
- shopify/merch language: merch drop, product page, add to cart, checkout, stock, size run

Avoid softeners:

- welcome
- explore
- beautiful
- handcrafted story
- premium lifestyle
- made for you
- our community
- fans
- customers

## 14. Release/Drop Naming Rules

Release names:

- Use uppercase track titles.
- Keep names blunt, memorable, and emotionally cold.
- Prefer weekday, room, object, pressure, and aftermath language.
- Avoid fantasy names, occult names, and cyberpunk names.

Good release title patterns:

- "PICK ME UP"
- "TUESDAY MORNING COMEDOWN"
- "ROPEMASTER"
- "ROOM INDEX"
- "STATIC HOUR"
- "RESTLICHT"
- "NO BRIGHT ROOM"
- "CONCRETE DAWN"

Drop/object naming:

- Use archive language, not merch language.
- Prefer study, index, form, object, material, proof.
- Do not imply active commerce until commerce is implemented.

Good object names:

- "GARMENT STUDY 001"
- "OBJECT STUDY 001"
- "MATERIAL TEST / BLACK"
- "RUNE INDEX FORM"
- "CHAIR ROOM PRINT STUDY"
- "POST-CLUB OBJECT"

Bad object names:

- "SHIBARI KAWAII merch drop"
- "limited occult tee"
- "dark streetwear collection"
- "exclusive fan hoodie"
- "cyber ritual capsule"

Release/drop metadata:

- CODE
- FORMAT
- ROOM
- MATERIAL
- STATUS
- SIGNAL
- ARTIST
- LABEL

Example:

- "FORMAT: OBJECT STUDY"
