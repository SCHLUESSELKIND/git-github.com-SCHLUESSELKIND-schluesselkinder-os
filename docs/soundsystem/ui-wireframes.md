# UI Wireframes

## Visual Direction

Dark industrial dub. Black and graphite surfaces. Neon green and dark mint as signal color. Sparse off-white text. The product should feel like a warehouse soundsystem machine, not a SaaS dashboard.

Avoid:

- friendly rounded SaaS cards
- pastel gradients
- explanatory marketing hero copy
- decorative cyberpunk noise
- generic music app playlists

Use:

- waveform-first layouts
- large action verbs
- machine status panels
- preset slabs
- dense console controls
- cinematic empty space where it increases tension

## Primary Navigation

First screen is the machine, not a landing page.

Large action-first navigation:

- CREATE TRACK
- BUILD RIDDIM
- GENERATE HOOK
- CREATE VOCALS
- STEM REMIX
- DUB FX LAB
- CHARACTER VOICE
- COVER GENERATION
- PROMPT LIBRARY
- STYLE DNA SYSTEM

The active action occupies the center. Secondary tools collapse into side rails.

## Screen 1: Command Console

Layout:

- Left vertical action rail with large text labels.
- Center waveform/empty project bay.
- Right machine-status rail: GPU, queue, engine, seed, safety.
- Bottom transport: play, stop, loop, export, compare.

States:

- idle: black bay with grid/tick marks
- queued: thin neon line scan
- generating: waveform skeleton grows over time
- blocked: red safety strip with terse reason
- export ready: green signal label, no celebratory UI

## Screen 2: Modular Prompt Builder

Not a form. It should feel like patching a console.

Controls:

- module banks for energy, bass pressure, vocals, atmosphere, structure
- visual preset cards with minimal names
- intensity sliders
- BPM/key/duration machine controls
- character selector
- negative prompt drawer

Each module click updates:

- compiled prompt preview
- safety status
- expected engine
- stem plan

## Screen 3: Waveform Workflow

Core interaction:

- full mix waveform top
- stem lanes below
- drag/drop stems into arrangement zones
- repaint region by selecting time range
- generate new stem into selected lane
- compare A/B takes

Stem lanes:

- DRUMS
- BASS
- VOCALS
- SYNTH
- FX
- ATMOS
- OTHER

## Screen 4: Character System

Character identity is not just a voice preset.

Panels:

- vocal language and delivery
- lyrical taboo/allowed words
- emotional temperature
- visual atmosphere
- style DNA adapters
- safety boundaries
- approved references

## Screen 5: Prompt Library

Library should organize reusable intent, not finished songs.

Views:

- action presets
- module combinations
- character prompts
- safety-approved templates
- failed prompts with reason
- high-performing internal prompts by manual producer rating

No fake engagement metrics.

## Screen 6: Style DNA System

Style DNA stores owned internal sound signatures:

- LoRA/LoKr adapters
- embedding neighborhoods
- approved training datasets
- sonic traits
- banned references
- adapter version history

Every profile must show rights basis and training source count.
