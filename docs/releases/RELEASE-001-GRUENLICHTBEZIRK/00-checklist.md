## §1. Mastering QA (Week 0 — operator-flagged)

Goal: confirm the `.wav` file in `SNUFFRAGGA EP/` is deliverable quality.
Distribution requires 16-bit/44.1kHz minimum, but masters should be 24-bit/44.1kHz
for streaming services that ingest higher quality (Spotify HiFi, Bandcamp lossless).

Run on a calibrated system or trusted reference monitors (NOT laptop speakers).

```
[ ]  Open each file in DAW or audacity. Check:
       - sample rate ≥ 44.1 kHz
       - bit depth ≥ 16 bit (24 bit preferred)
       - mono / stereo as intended (no accidental mono-summed)
       - duration matches your performed length
       - no clicks at start/end (silence ≥ 0.1s before first transient)

[ ]  Loudness reference (LUFS integrated):
       - Spotify ingests at -14 LUFS — anything louder gets normalized down
       - Target: -10 to -14 LUFS integrated for club / sub-bass material
       - Hard ceiling: True Peak ≤ -1.0 dBTP (-1.5 dBTP if you want safety margin)
       - Tool: youlean LUFS meter (free), Reaper's master FX, ffmpeg
         `ffmpeg -i track.wav -af loudnorm=print_format=summary -f null -`

[ ]  Sub-bass check on headphones AND on a real sub system:
       - Frequencies below 30 Hz: cut unless intentional
       - 30–60 Hz: this is GRÜNLICHTBEZIRK territory, must be clean
       - check phase coherence in stereo (mono compatibility — sub should not cancel)

[ ]  Format conversions for distribution:
       - Master:     24-bit / 44.1 kHz WAV (one per track)
       - Backup:     16-bit / 44.1 kHz WAV (DistroKid fallback)
       - Reference:  320 kbps MP3 (for short-form video bed)

[ ]  Decision log:
       - if any track is rough → mastering pass at studio OR online service
         (Distrokid offers a $9.99/track masters; LANDR €5; manual via Ozone)
       - if QA passes → check master ready
       - if QA fails → log reason in release-log.md, decide slip vs. master-pass
```
