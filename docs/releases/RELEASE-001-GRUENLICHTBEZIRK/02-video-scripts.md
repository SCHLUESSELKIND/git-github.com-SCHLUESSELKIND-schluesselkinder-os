### Shot list

```
0.0 – 1.5s    BLACK FRAME, white text top-left, mono 11pt:
              "TRANSMISSION TEST · 0612"
              audio: hiss only

1.5 – 4.0s    HARD CUT to: low-light footage — a streetlight against fog,
              or a flickering fluorescent tube in a hallway.
              audio: low-pass GRÜNLICHTBEZIRK bed, sub barely audible

4.0 – 7.0s    HARD CUT to: macro on something concrete/industrial
              (bollard, paint stripe, rust, exit sign).
              text bottom-right, mono 9pt: "SNUFFRAGGA SOUNDSYSTEM"
              audio: low-pass releases at 6.0s — drum / sub punch arrives

7.0 – 12.0s   HARD CUT to: handheld walking through a corridor / underpass.
              shaky. one continuous take.
              text bottom-left, mono 13pt: "GRÜNLICHTBEZIRK"
              audio: full bed

12.0 – 14.5s  HARD CUT to: BLACK FRAME, green dot pulses 3× at center.
              text below dot, mono 9pt: "12.06 · 00:00 CET"
              audio: bed continues, ends abruptly at 14.5s on a beat

14.5 – 15.0s  BLACK + silence. No outro card. No logo. No "follow me."
```

### Production realism

- Camera: any iPhone 12 or later in lock-exposure mode.
- Light: existing only — streetlamps, fluorescents, hallway. Never add light.
- Color grade: crush blacks (clip at 8%), desaturate everything except any green
  light source already in frame. Add 8% film grain.
- Cut on beat — the hard cuts should land on the kick. If they don't, recut.
- Vertical from the start; do NOT shoot horizontal and crop.
- Total shoot time: ~90 minutes if scouted, 3 hours if not.

  approx 19:30–19:45 in central Europe in June.

## Hashtag doctrine (all videos)

- Max 3 hashtags. Always.
- Always include `#snuffragga` and `#schluesselkinder` (for archive search).
- Third hashtag rotates: `#grünlichtbezirk` (drop window), `#soundsystem` (post-drop),
  `#dub` / `#basspressure` (genre-relevant), `#berlinunderground` (geographic, if true).
- NEVER use: `#fyp`, `#viral`, `#newmusic`, `#producer`, `#electronic`, `#techno`,
  any meme-tag. These dilute brand and pull the wrong audience.

---

## Caption doctrine

- Lowercase by default.
- No emojis. No "→" except as text-arrow inside the brand voice. No "out now."
- Maximum 7 words.
- The caption is a status announcement, not a sales pitch.
